# Смена на ПВЗ

Браузерная игра: вы — сотрудник пункта выдачи Ozon. Нужно отработать смену: принять
поставку у курьера, обслужить клиентов, оформить возвраты, разобраться с
конфликтными посетителями и закрыть смену без лишних замечаний.

## Запуск

Откройте `index.html` в браузере (файл можно запускать и без сервера).

## Управление

- **Клик по посылке на полке** — выдать заказ клиенту
- **1–4** — выбрать вариант ответа
- **Пробел / Enter** — продолжить диалог
- Кнопка «Позвонить» в списке дел — выполнить обещание клиенту

## Как устроена смена

1. **Приёмка поставки.** Курьер привозит коробки, у вас накладная. Сверьте
   списки: если позиции не хватает — отметьте её в накладной, иначе нажмите
   «Всё сошлось».
2. **Обслуживание клиентов.** У каждого клиента свой сценарий:
   - **Выдача** — найдите заказ по номеру на полках и щёлкните по коробке.
     Растерянный клиент номера не помнит: ищите по городу и категории товара.
   - **Вопрос по статусу** — ответ нужно взять из карточки заказа в системе.
   - **Возврат** — у клиента разные причины: вскрытая упаковка, брак, «передумал».
     Правильный ответ зависит от причины.
   - **Жалоба** — конфликтный клиент: сначала нужно снять раздражение, потом
     предложить решение. Если клиент уже разозлён — вызывайте старшего смены.
3. **Обещания.** Если пообещали перезвонить, задача появится в списке дел.
   Невыполненное обещание — минус 200 ₽ и репутация.
4. **Закрытие смены.** Сверьте остатки по системе (в утверждениях есть ложные) и
   закройте смену в приложении.

## Что влияет на результат

- **Репутация** (0–100) — растёт от довольных клиентов, падает от ошибок.
  От неё зависит премия и количество звёзд в конце смены.
- **Терпение клиента** — у каждого свой запас времени, у занятых клиентов он
  меньше. Если клиент не дождался, он уходит недовольным.
- **Деньги** — оклад + премии за клиентов + премия за репутацию − штрафы.

## Клиенты

| Тип | Повадки |
| --- | --- |
| Добрый | Благодарит, доволен любым аккуратным ответом |
| Обычный | Нейтрален, ждёт своей очереди |
| Занятой | Торопится, терпения мало |
| Растерянный | Не помнит номер — ищите по городу и категории |
| Конфликтный | Раздражён, требует решения и не любит ждать |
| С VIP-картой | Постоянный клиент, ждёт приоритета |

## Смены

1. **Утро, будний день** — 5 клиентов, знакомство с работой.
2. **День, будний день** — 7 клиентов, появляются конфликты.
3. **Вечер пятницы** — 9 клиентов, все хотят забрать заказы.
4. **Суббота, пик продаж** — 12 клиентов, очередь до закрытия.

Лучший результат по каждой смене сохраняется в браузере.

## Файлы

- `index.html` — разметка
- `style.css` — оформление
- `data.js` — смены, типы клиентов, сценарии диалогов
- `art.js` — рисование сцены (зал, полки, персонажи)
- `game.js` — движок: состояния, диалоги, оценка, итоги
